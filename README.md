# 台股大盤風險分數（MVP）

把市場狀態換算成 **10–100 分**；10分代表仍保留市場基礎風險，分數愈高代表風險愈高。四項子分數目前各占25%。這是風險溫度計，不是買賣訊號。專案已完成第一輪 walk-forward 歷史校準，結果與限制見 `CALIBRATION.md`。

## 資料格式

CSV 每列是一個交易日，日期可排序且至少 120 列：

```csv
date,close,volume,margin_balance,turnover_value,foreign_net,investment_trust_net,dealer_net
2026-01-02,23000,4200000000,320000000000,480000000000,12000000000,1000000000,-500000000
```

- `volume`：成交量（股或張皆可，但全檔須一致）
- `margin_balance`：融資餘額
- `turnover_value`、三項 `*_net`：金額單位必須一致；買超為正、賣超為負
- 程式由原始欄位自動計算季線（60 日）、半年線（120 日）、20 日均量、融資 3/5/20 日變化與法人占成交值比例

## 執行

```bash
python3 twse_scraper.py --months 8 --output market.csv
python3 risk_score.py market.csv
python3 risk_score.py market.csv --json
python3 dashboard_server.py
python3 backtest.py market.csv
python3 -m unittest -v
```

啟動儀表板後開啟 <http://127.0.0.1:8000>。預設讀取專案內的 `market.csv`；也可用 `python3 dashboard_server.py --csv 其他資料.csv --port 8080`。介面包含總分儀表、四項子分數、指數與均線、風險分數趨勢，以及最新三大法人買賣超。

做多入場提醒頁位於 `/dashboard/entry.html`。它使用收盤後資料，依總風險分數、指數與季線位置、季線斜率及20日動能，判斷下一交易日為「適合分批做多／可考慮分批／接近條件／暫不適合」，並列出未通過條件。訊號門檻取自 `CALIBRATION.md` 的歷史檢查，只作風險管理參考。

做多訊號的出場週期固定為十個交易日。`python3 long_entry_backtest.py market_history.csv` 會以訊號後一交易日收盤作進場代理、第十個交易日收盤出場，並輸出 `long_entry_backtest_report.json`；主要統計採持有期間不重複進場的交易，以免連續訊號灌高樣本數。也可用 `--holding-days` 測試其他持有期。做空監控維持三個交易日。

做多與做空已拆成獨立頁面：`/dashboard/entry.html` 與 `/dashboard/short.html`。做空監控條件為總風險至少40分、指數跌破季線、季線斜率為負、三大法人合計賣超。1,500日資料中四條件全期三日做空勝率50.81%，尚不足以宣稱為已驗證的進場訊號；介面只顯示「做空觀察」。正式啟用前仍需納入融券或反向ETF成本。

### 環境變數

部署環境可設定 `HOST`、`PORT`、`CSV_PATH`、`AUTO_REFRESH_MINUTES`、`TWSE_REFRESH_MONTHS`、`TWSE_REFRESH_LIMIT` 與 `TWSE_REQUEST_DELAY`。命令列參數優先於環境變數；設定範例見 `.env.example`。本機可執行 `set -a; source .env; set +a; python3 dashboard_server.py`。`.env` 已排除於版本控制，請勿把密鑰提交到 repository。TWSE 目前使用的公開資料端點不需要 API key。

## 公開部署

專案附有 `render.yaml`，可用 Render Blueprint 部署。Web Service 會監聽平台提供的 `PORT`，提供 `/healthz` 健康檢查，並在啟動後每6小時補抓證交所資料。將整個專案（包含作為啟動基底的 `market.csv`）推送至 GitHub，再於 Render 選擇 **New → Blueprint**、連接該 repository 並套用 `render.yaml`；完成後會取得公開的 `https://...onrender.com` 網址。

`.github/workflows/update-market.yml` 會在週一至週五台灣時間19:00自動抓取最新完整交易日。資料有變化時，GitHub Actions 只提交 `market.csv`，再由 Render Auto-Deploy 更新網站；休市或資料尚未完整時不會產生空提交。GitHub 排程不是即時排程器，尖峰時可能延遲數分鐘，也可在 Actions 頁面手動執行 `Update TWSE market data`。

若不用 Blueprint，可在 Render 的 **Environment** 頁面依 `.env.example` 新增同名變數；`PORT` 通常由 Render 自動提供，不必手動建立。秘密值請用 Render 的 Secret 類型保存。

免費服務的檔案系統不是永久儲存；服務重啟時會回到Git版本中的 `market.csv`，之後再自動補抓。長期正式營運應改用PostgreSQL或付費持久磁碟，並將更新工作拆成單獨排程。

`twse_scraper.py` 使用證交所官方 `FMTQIK`（市場成交資訊）、`MI_MARGN`（信用交易統計）與 `BFI82U`（三大法人）端點。首次建立 140 日資料約需 280 次逐日請求；已寫入的日期會作為快取，之後執行只補缺漏日。可用 `--delay 0.5` 調低請求頻率，或用 `--end 2026-07-20` 指定截止日。

同一天的成交、融資與法人報表發布時間可能不同。若當日盤後資料尚未齊全，程式會略過該日並產出截至前一完整交易日的 CSV；稍後或隔日重跑便會自動補抓。

> 融資餘額採集中市場「融資金額（仟元）今日餘額」並換算成元；法人自營商為「自行買賣＋避險」，外資自營商不重複計入。CSV 僅含上市集中市場，未合併上櫃資料。

分級為：80–100高風險、60–79.9中高風險、40–59.9中低風險、10–39.9低風險。底層規則先計算安全程度，再以 `max(10, 100 - 安全分)` 統一轉成對外風險分數。

技術位置子分數不只看季線乖離，而由季線相對位置 35%、收盤／20／60／120 日均線排列與季線 20 日斜率 30%、20 日動能 15%、距 60 日高點回撤 20% 組成。正乖離或 20 日漲幅過大會視為過熱而降低安全分，超過近期乖離分布 2 個標準差另行扣分。

法人態度除了當日外資／投信／自營商方向及連續性，也納入「5／20 日買賣超力度」：先將每日法人合計買賣超除以成交值，再把當日占比相對前 5 與 20 個交易日（均不含當日）標準化為 z-score。短線 5 日占 40%、中期 20 日占 60%；合成力度每 ±1 個標準差調整法人子分數 ±6 分，上限 ±18 分。

市場量能子分數由 20 日量能常態程度 40%、價量方向確認 35%、相對前一日量能 10%、20 日成交量變異係數所代表的穩定度 15% 組成。急跌爆量、急漲量縮，以及急漲爆量同時融資追價均視為較高風險。

儀表板的「市場加權融資維持率」按 `Σ（個股融資餘額交易單位 × 1,000 股 × 個股收盤價）÷ 集中市場融資金額 × 100` 推估。它以證交所個股明細計算，但仍不是證交所公布的整戶維持率，也不含個別帳戶的融券、抵繳擔保品與實際成本；130% 為法規追繳門檻。

融資槓桿子分數由「融資 3／5／20 日變化」占 60%、「市場加權維持率」占 40% 組成。維持率分段為：低於 130% 得 0–15 分、130–150% 得 15–40 分、150–160% 得 40–60 分、160–170% 得 60–75 分、170–180% 得 75–90 分、180%以上得 90–100 分。沒有維持率資料的歷史日期只採融資變化分數。

取得完整個股明細時，融資槓桿改由速度 50%、維持率 30%、結構 20% 組成。速度除 3／5／20 日變化外，還考慮連續增減天數、相對融資20日均值，以及20日融資增速減去指數報酬的超額堆槓桿；跌勢中急減視為斷頭風險，反彈中急減才視為健康去槓桿。結構分數包含融資市值 Top-10 集中度 35%、HHI 15%、前三大產業集中度 20%、融資占股本達10%以上標的曝險 20%、整體券資比 10%。

## 下一步

`backtest.py` 採 expanding-window walk-forward：每個評分日只使用當時及以前資料，計算未來 5／20 個交易日最大回撤，並依現行四段風險區間輸出樣本數、平均／中位數／90 百分位回撤與 Spearman 排序相關。結果寫入 `backtest_daily.csv` 和 `backtest_report.json`。至少累積兩年／500 個交易日且涵蓋多空循環後，才適合依報告校準門檻。

完整歷史校準可先執行 `python3 twse_scraper.py --months 80 --limit 1500 --output market_history.csv`，再以 `python3 backfill_structure.py market_history.csv` 回補每日維持率及融資集中結構，最後執行 `python3 backtest.py market_history.csv`。兩個抓取程序都會寫入檢查點，可在中斷後用相同命令續抓。

目前1,500個交易日的延長回測已完成，期間為2020-05-21至2026-07-21。10分下限版本的候選分界為21.8／28.2／41.6，但尚未取代介面的40／60／80分界；需以之後完全未參與調參的新資料再次驗證，再決定是否升級為正式門檻。
